Detailed Description

One commit/release instruction: "the box that nominally won you did/didn't actually commit" – the wire record for the carve protocol's Phase 3 (sent by a proposer to each foreign member's owner, once the proposer's own box's final outcome is known).

Trivially copyable (see KDClaim). This, not KDVerdict, is what actually authorizes an owner to delete a particle – see KDVerdict's own docs for why a nominal win/loss result by itself is insufficient.
