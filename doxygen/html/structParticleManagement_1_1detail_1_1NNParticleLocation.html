Detailed Description

Result of locating a physical position against the AMR grid – see placeMergedParticles().

Deliberately independent of any AmrMesh/Realm/ParticleContainer type (this header stays Amr-agnostic) – mirrors LevelTiles::LevelAndBox's fields exactly, since that IS the intended real implementation: an O(1) point->block query on the realm's LevelTiles tile->box hash (the SAME lookup a ParticleContainer already uses internally to route its own particles during remap()), never a linear scan over patches. Reusing ParticleContainer::findDestination() rather than adding a second, parallel point-location method keeps this one mapping the single source of truth for "which box owns this position".
