Detailed Description

Domain boundary conditions for PetscHelmholtzOp, taken from ElectrostaticDomainBc.

This mirrors EBHelmholtzElectrostaticDomainBC: it holds a Dirichlet or Neumann BC object on each domain side and routes the calls to it. The BC values are evaluated whenever getBoundaryData is called, so time-dependent values (FieldSolver captures its time by reference) enter through the right-hand side.
