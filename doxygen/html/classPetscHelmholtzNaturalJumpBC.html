Detailed Description

The natural jump condition b_0 * D_0 + b_1 * D_1 = sigma on the interface between two phases.

The closure eliminates phi_B with phi_B = (sigma - b_0 sum_i w_0,i phi_0,i - b_1 sum_i w_1,i phi_1,i) / (b_0 w_B,0 + b_1 w_B,1), so the flux into each side couples the rows of both phases, and g = sigma. The jump data is an input, so updateJumpData does nothing.
