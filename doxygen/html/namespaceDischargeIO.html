std::string DischargeIO::gitHash ( )
noexcept

Get the git description of the source tree that this executable was compiled from.

The string is stamped into the library at compile time by Lib/GenerateGitHash.sh, and is the output of 'git describe –tags –always –dirty' – e.g. "v26.08-26-ge5f3ef39d" or, if the working tree had uncommitted changes, "v26.08-26-ge5f3ef39d-dirty". It is the string "unknown" if the source tree was not a git repository when it was compiled, or if git was not available.

Returns
Git description of the compiled source tree.

Write an SoA particle container to an H5Part file (quick visualization).

Position, id and weight are taken from the container-owned columns and written automatically. The payload datasets are derived declaratively from the optional Traits::h5PartColumns tuple (a list of H5Part::Scalar / H5Part::Vector descriptors pairing a dataset name with the selecting payload member pointer(s)); if Traits::h5PartColumns is not declared, only id/position/weight are written. Each vector descriptor is written as name-x/name-y/name-z.
