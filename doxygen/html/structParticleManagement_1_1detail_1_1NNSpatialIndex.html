Detailed Description

template<typename Packed, typename Cloud = EBGeometry::PointCloudBVH<Real, ParticleID>>
struct ParticleManagement::detail::NNSpatialIndex< Packed, Cloud >

A patch's spatial index for one round: an EBGeometry point-cloud index (PointCloudBVH or PointCloudHashGrid, selected via Cloud) over the whole patch (every local valid particle followed by every ghost) plus its precomputed k-nearest-neighbor graph.

Built once per patch per mergeNearestNeighborsTree()/mergeNearestNeighborsHash() call via buildNNSpatialIndex() and reused across every internal a_iterateLocalTierToConvergence pass via lazy deletion (see findNearestNeighborCandidates()'s own docs). A patch with no crowded cell gets no index at all (pointCloud stays null – see buildNNSpatialIndex()'s per-cell pre-filter). The point cloud's metadata is each point's globalID; a hit's cloud index c decodes ownership directly: c < pointCloudNLocal => local valid a_localValid[c], else ghost a_ghosts[c - pointCloudNLocal].

Template Parameters
PackedSee NNMergeParticle.
CloudEBGeometry point-cloud index type – EBGeometry::PointCloudBVH<Real,ParticleID> (default, used by mergeNearestNeighborsTree()) or EBGeometry::PointCloudHashGrid<Real,ParticleID> (used by mergeNearestNeighborsHash()). The two expose an identical query interface (same Hit shape, same method names), so every consumer of this struct is written once and works for either.
