Detailed Description

template<typename Packed>
struct ParticleManagement::detail::NNSpatialIndex< Packed >

A patch's spatial index for one round: an EBGeometry SIMD PointCloudBVH over the whole patch (every local valid particle followed by every ghost) plus its precomputed k-nearest- neighbor graph.

Built once per patch per mergeNearestNeighborsRound() call via buildNNSpatialIndex() and reused across every internal a_iterateLocalTierToConvergence pass via lazy deletion (see findNearestNeighborCandidates()'s own docs). A patch with no crowded cell gets no index at all (pointCloud stays null – see buildNNSpatialIndex()'s per-cell pre-filter). The point cloud's metadata is each point's globalID; a hit's cloud index c decodes ownership directly: c < pointCloudNLocal => local valid a_localValid[c], else ghost a_ghosts[c - pointCloudNLocal].
