Detailed Description

template<typename Packed>
struct ParticleManagement::NNMergeParticle< Packed >

Minimal, payload-agnostic description of one particle as input to the nearest-neighbor merge.

Carries what the matching/decision logic needs – position, weight, a globally unique id, the particle's current owning rank, and its AMR level – plus an opaque, caller-defined reconciliation payload. The matching/decision logic never inspects payload; it is unpacked only by the caller-supplied combine callback when a pair is finalized.

Template Parameters
PackedCaller-defined payload type (e.g. a single Real energy for ItoParticle, or an empty struct if no type-specific reconciliation data is required). Must be copyable and trivially linearizable (NNMergeProposal ships two of these as one atomic pair).

◆ level

template<typename Packed >
int ParticleManagement::NNMergeParticle< Packed >::level

The AMR level this particle currently lives on.

Required for multi-level correctness: cellKeyOf() needs the dx of the level the particle lives on, and a ghost candidate can be on a different level than the querying patch (GhostType::Coarse/Fine, not just SameLevel). Every cell-key computation uses the per-level dx for this field, never a single global dx (see a_dxByLevel in resolveTrivialTier()/ judgeProposals()).
