Detailed Description

Dirichlet boundary condition phi = phi_B on the EB faces, for PetscHelmholtzOp.

The flux is the one-sided normal derivative from PetscHelmholtzEBStencils, F = w_B * phi_B + sum_i w_i * phi_i, so g = phi_B.
