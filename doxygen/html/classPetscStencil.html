Detailed Description

A linear stencil over global PETSc rows, i.e. a list of (row, weight) pairs.

This plays the role that VoFStencil plays for Chombo data, but each entry is a global PETSc row rather than a VolIndex. A VoFStencil entry is only meaningful together with the level and grid patch it was built on, whereas a PetscStencil entry can be passed directly to MatSetValues.

Entries are appended by add() and operator+= without looking for an existing entry with the same row, so a row can appear more than once until compress() is called. compress() sorts the entries by row and merges duplicates, which makes the rows unique and ascending. Duplicates are summed in the order they were added, so the result is the same as merging on every add, bit for bit. Call compress() before passing the entries to MatSetValues: duplicate rows would be summed with ADD_VALUES but would overwrite each other with INSERT_VALUES. Building a stencil of N entries this way costs O(N log N), compared with O(N^2) for merging on every add; at a hundred entries the difference is roughly a factor of three to five.

void PetscStencil::compress ( )
noexcept

Sort the entries by row and merge entries with the same row by summing their weights.

After this the rows are unique and in ascending order, which is the cheapest order for MatSetValues. The sort is stable, so the weights of a row are summed in the order they were added.
