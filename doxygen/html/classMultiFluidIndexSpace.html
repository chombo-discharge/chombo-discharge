Detailed Description

Two-fluid index space.

This is basically a wrapper for using two Chombo EBIndexSpaces in the simulation. It calls Chombo for building the EBIS'.

Define the index spaces in filler mode: each phase's EBIndexSpace fills every layout through its filler and holds no level of its own.

See EBIndexSpace::define. A phase whose filler is empty has no index space.

Parameters
[in]a_domainsThe domains, finest first, each a coarsening by two of the one before.
[in]a_originLower-left corner.
[in]a_finestDxResolution on the finest domain.
[in]a_fillersOne filler per phase, indexed by phase::which_phase. The gas phase's must not be empty.

IntVectSet MultiFluidIndexSpace::interfaceRegion ( const IntVectSet & a_gasCutCells,
const IntVectSet & a_solidCutCells ) const

Get the interface region: the cells cut in both phases.

Each rank passes the cut cells it holds of each phase; they are gathered on rank 0, intersected there and broadcast, so every rank returns the whole region. Collective.
