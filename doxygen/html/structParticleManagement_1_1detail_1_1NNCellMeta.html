Detailed Description

Per-point metadata carried by a one-cell spatial index's PointCloudBVH: a particle's global id and whether it is a local-valid particle of the patch the index was built for.

Unlike NNSpatialIndex (one whole-patch cloud, ownership decoded from cloud-index position), each one-cell cloud is built independently per cell, so ownership is carried directly as metadata instead.
