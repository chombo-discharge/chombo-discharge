Detailed Description

template<typename Packed>
struct ParticleManagement::KDParticle< Packed >

Minimal, payload-agnostic description of one particle as input to the kd-tree carve merge.

Carries what the tree build/carve protocol needs – position, weight, a globally unique id, and the particle's current owning rank – plus an opaque, caller-defined payload (e.g. energy). The build/carve logic never inspects payload; it is unpacked only by the caller-supplied combine callback when a leaf/box is finalized. No AMR-level field is carried (unlike the nearest-neighbor merge's NNMergeParticle): the tree build only ever needs physical position (level-independent) and this patch's own cell spacing, never a per-particle level.

Template Parameters
PackedCaller-defined payload type (e.g. a single Real energy for ItoParticle).
