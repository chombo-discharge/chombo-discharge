Detailed Description

Per-cell particle-count histogram over one patch's gathered particles.

Built once from every particle's own position, so it is unaffected by how buildKDQuotaLeaves() later partitions the space – a node-local count is NOT a safe substitute, see that function's own docs for why. Stored sorted by cell index and looked up by binary search, and callable directly, so it satisfies buildKDQuotaLeaves()'s CellTrueCount requirement as-is. Shared by mergeKDCarve() and mergeKDPatch(): both need the same ground truth, and the invariant that it is built from true positions rather than from the partition is easy to break if each keeps its own copy.
