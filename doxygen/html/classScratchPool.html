Detailed Description

Pool of temporaries on one Realm, reused between the functions that need them.

The pool keeps every temporary it has built, together with the key it was built for (phase, level, number of components, ghost cells) and whether it is in use. acquire() hands out a free entry with a matching key, or stores a new one, and returns a Scratch that gives it back when destroyed. The pool therefore grows to the largest number of temporaries in use at the same time, and keeps them, Copiers and communication buffers included, until the grids change.

The pool only does the bookkeeping; the caller (AmrMesh) builds the data. Entries are built on the Realm's current grids, so the owner must call clear() whenever the grids change. clear() aborts if a temporary is still in use, so a Scratch can never refer to data on old grids.

Every call aborts when made inside an OpenMP parallel region. Temporaries are fetched and returned at the level of the hierarchy, never per box, so the pool needs no lock.
